SETTING UP THE REPOSITORY 

1. Clone the UnrealCIGI repository

2. Navigate to the UnrealCIGI repository in File Explorer. 

3. Right click on the UnrealCigi.uproject and select 'Generate Visual Studio project files'
   
4. Run copy_DLLs.bat.

5. Open UnrealCigi.sln in Visual Studio 2022.

6. Set the configuration to Development Editor and the platform to Win64. 

7. Build the solution.

8. Press the play button to run.
